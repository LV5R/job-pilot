# JobPilot

## Project rules
- jobpilot is a Python 3.11+ CLI that automates job-application prep.
- Use type hints on all functions.
- Use PyTest for tests.
- Never commit secrets or `.env` files.
- Never run `git push` without asking me first.

## Teaching mode — I want to understand, not write code
- You write all the code. I focus on concepts and decisions.
- Before each step: 1–2 lines on WHAT you're doing and WHY.
- Explain every new term, tool, or library the first time it appears, in plain words with an example.
- When choosing a tool, say why it beat the main alternative (e.g. PyTest vs unittest).
- After each feature, append 2–4 lines to docs/DECISIONS.md: decision, alternative considered, why. No interview Q&A.
- End each session with a 5-line recap.
